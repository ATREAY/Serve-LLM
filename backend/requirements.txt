# scripts/sbatch_serve.sh), not on the login node: vllm + torch pull in
# several GB of CUDA wheels.
#
# torch/torchvision are pinned to a CUDA 12.1 build because `pip install
# vllm` alone resolves to the latest vllm, which hard-pins torch==<latest>+cu13
# — and every GPU node on this cluster has a driver too old for CUDA 13
# (535.x on dgx-a100-02, 570.x on the P100/V100 nodes). vllm==0.6.3.post1
# hard-pins torch==2.4.0, which has an official cu121 build all of them
# accept. Verified end-to-end on dgx-v100-01 (see scripts/sbatch_serve.sh
# for why v100, not a100 or p100, is the actual serving target here).
